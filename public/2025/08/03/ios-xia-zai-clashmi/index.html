软件下载方式

第一步：注册美区Apple ID

下方视频加载太慢的话，可以抖音搜索注册美区ID的方法

免费注册教程： https://static.1224323.xyz/USappleid.mp4

教程文字解析

1.先去官网注册一个国内的AppleID

  • 注册地址 https://account.apple.com/account

2.注册登录之后，更改国家或地区以及语言

  • 美国地址生成 https://www.meiguodizhi.com
  • 最好生成一个“蒙大拿州”的地址，因为免税
  • 付款类型选择“无”
  • 地址填写上面网站生成的就可以了
  • 语言选择“美国英语”

3.更改保存成功以后，就可以在AppStore登录并下载软件了

  • 首次登录如果提示此AppleID尚未在iTunes Store中使用过
  • 点击检查 → 同意条款 → 然后付款方式不用修改（如果是必填，那就选择“无”），地址再填一遍，和上面生成的地址一样，电话号码随便填，区号三位，电话7位，例如232 2431145随便填，格式正确即可

第二步：下载安装ClashMi

用美区ID登录AppStore

搜索ClashMi并下载

使用ClashMi

首次使用请先配置

打开 ClashMi → 点击 核心设置 → 点击 覆写 → 选择 不覆写

使用方法

第一步：导入订阅

在仪表盘中找到一键订阅，复制订阅地址


打开 ClashMi → 点击 我的配置 → 点击 + → 选择 从剪切板导入 → 备注填写机场名字即可→ 右上角保存

第二步：开启代理

ClashMi首页点击右上角开关

第三步：测速选择节点

点击代理 → 右上角测速 → 测速结束后选择第一个 → 选则你想使用的节点

代理模式说明

规则模式（推荐）

  • 根据规则分流访问。 国内网站（如百度、微博、微信）不走代理，国外网站才走代理。

全局模式

  • 所有流量都会通过代理服务器访问。 国内网站同样会走代理，可能导致速度变慢并消耗套餐流量。

直连模式

  • 所有流量直接访问目标地址，不使用代理。 开启后将无法访问境外网站。

连接后无法使用

如果连接后无法上网，请按以下步骤排查：

  1. 确认订阅对应的服务套餐未过期。
  2. 确认当前选择的节点是可用节点。
  3. 确认代理模式不是直连（Direct）。
  4. 尝试更新订阅重新导入节点。
  5. 尝试切换流量/WiFi或重启路由器、光猫。
  6. 尝试重启设备。
  7. 删除App后重新安装。
